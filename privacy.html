プライバシーポリシー

更新日：2026年10月27日

Bearer Quant Backup は、運用者本人が管理するバックアップと復元のためにGoogle Drive APIを利用します。

アクセスする情報と利用目的

接続先を確認するためのアカウントのメールアドレスとストレージ使用量、バックアップ・復元対象のファイル内容、ファイル名、サイズなどの情報を利用します。rcloneのDriveアクセス権限を要求しますが、本ツールの処理対象は運用者が指定したバックアップフォルダです。

保存と共有

バックアップは運用者が指定したGoogle Driveとローカル環境に保存します。認証情報は運用者専用のアクセス権を設定したローカルの秘密情報領域に保存し、バックアップにもこのサイトにも含めません。本ツールはDriveの共有設定を変更しません。Drive上の既存の共有設定と、運用者が別途行う共有は引き続き適用されます。

Google APIから取得した情報を、広告、販売、または汎用AIモデルの学習に利用しません。Google APIから受け取った情報の利用および他のアプリへの転送は、Limited Use要件を含むGoogle API Services User Data Policyに従います。

保持と削除

復元可能な世代を残すため、バックアップは運用者が削除するまで保持します。運用者はGoogleアカウントの接続管理画面からアクセス許可を取り消し、Driveおよびローカルの保存物を削除できます。アクセス許可の取り消しだけでは、作成済みのバックアップは削除されません。

問い合わせ

本人または本人が許可した開発者のみが使用するツールです。問い合わせは運用者への既存の連絡経路を使用してください。
